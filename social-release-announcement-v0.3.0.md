# Faliz Games v0.3.0 — Social Release Announcement Pack

## Core announcement

**Faliz Games v0.3.0 is here.**

A faster, more polished terminal game catalog for discovering, searching, filtering, and downloading games from the command line.

What’s new:

- Professional adaptive terminal dashboard
- Top 100 best-rated games
- Search, platform filters, extension filters, and sorting
- Multi-game download queue
- Live speed and ETA telemetry
- Press `P` to pause or resume
- Press `C` to cancel while preserving resumable data
- Safer `Ctrl+C` interruption handling
- Termux shared-storage support
- Clickable developer social links

Install directly from the public repository:

```bash
npm install --global git+https://github.com/gamesiteonline/faliz-games-downloader-cli.git
faliz-games
```

GitHub: https://github.com/gamesiteonline/faliz-games-downloader-cli

## Reddit

Faliz Games v0.3.0 — a polished terminal game catalog with pause/resume downloads

### Body

I’ve released Faliz Games v0.3.0, a Node.js CLI focused on making game discovery and downloads feel more like a professional terminal dashboard.

The new release includes:

- Adaptive layout for desktop terminals and Termux
- Top 100 rated-games view
- Search by title, genre, platform, or extension
- Platform and extension filters
- Rating, title, and size sorting
- Multi-game selection and sequential download queue
- Live transfer speed, bytes, and ETA
- `P` pause/resume controls
- `C` cancel controls with partial-file preservation
- Safe `Ctrl+C` interruption and resume support
- Downloads-folder support on Termux and desktop systems

Install from the public repository:

